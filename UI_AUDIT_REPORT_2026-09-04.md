## 🔴 Критические проблемы

### 1. Рассинхронизация frontend/backend на сервере (кластер 404/500)
Развёрнутый фронтенд новее бэкенда — страницы вызывают эндпоинты, которых на сервере нет:

| Экран | Что сломано | Скриншот |
|---|---|---|
| «Бренды» (`/brands`) | `/api/v1/public/brands` → 404, красная плашка «Not Found» + «Повторить» | `s02_brands.png` |
| «Администрирование» | `/api/v1/admin/managers` → 404; **создать менеджера нельзя** — главная админ-функция недоступна | `s33_admin_page.png` |
| Экспорт заявки | PDF (`export/pdf`) → 404, Excel (`export.xlsx`) → 500 | `s23_manager_order_detail.png` |
| «Бренды» менеджера (`/manager/brands`) | оба API отвечают 200, но страница падает (ошибка сборки фронтенда) | `s29_manager_brands.png` |

Хуже всего — «Администрирование»: поверх ошибки рисуется пустая таблица «Менеджеров пока нет», что маскирует сбой под «просто пусто».

### 2. Мобильная навигация менеджера отсутствует
На 390px у менеджера **нет ни нижнего таб-бара, ни бургера** — сайдбар скрыт (`width: 0`), в шапке только валюта и аватар, из которого доступны лишь «Профиль»/«Уведомления». Попасть в заявки/клиентов/бренды можно только прямым URL. У клиента таб-бар есть (`m10_mobile_profile_menu.png`), у менеджера — нет. Кабинет менеджера на телефоне фактически неработоспособен.

### 3. Локальный стек: сайт падал целиком
Дублирующий `</td>` в `apps/web/pages/catalog/index.vue` (~строка 586) ронял **весь сайт** (Vite «Invalid end tag» → HTTP 500 на любой странице). Исправлено локально, **правка не закоммичена** — нужно закоммитить и задеплоить.

Дополнительно: `NUXT_PUBLIC_API_BASE=""` в `infra/docker-compose.yml` заставляет ходить только через nginx `:8081`; дев-сервер `:3000` ломает все API-вызовы («No match for /api/v1/...») — неудобно для разработки.

## 🟡 Юзабилити и консистентность

1. **Системные тексты на английском** в русском интерфейсе: «Not Found» на пользовательских экранах (`s02`, `s33`) — нужно человекочитаемое «Не удалось загрузить…».
2. **Мобильный клиент**: в таб-бар (Главная/Каталог/Заявки/Аналитика) **не попали** «Избранное», «Массовое добавление», «Файлы» — прямые URL работают, но точки входа нет.
3. **Таблица заявок на мобильном**: кнопка обрезана до «Повтори», иконки-действия без подписей; горизонтальную прокрутку таблицы (796px в контейнере, скролл работает) ничего не подсказывает — ни тени, ни индикатора (`m12`).
4. **Лендинг без мобильного меню** — гостевые страницы не имеют бургера, навигация по кабинетам недоступна с телефона (`m01`).
5. **Тёмная тема — работает** (ретест подтвердил): переключается в профиле, применяется мгновенно, переживает перезагрузку (ключ `nuxt-color-mode-v2`) — `d40_dark_theme_profile.png`.
6. Кнопка «Скачать PDF» на карточке заявки не сообщает заранее, что может упасть 404; состояние загрузки есть, ошибки — нет.
